**Home three-intent mandate (founder, 2026-09-08):** Home must make it VERY CLEAR which of three modes the user is in — (1) NEARBY (find places around me), (2) SMART SEARCH, (3) BROWSE/DREAM — "and we go from there, not just nearby services." Priorities: perfect packages, sell dream vacations, beautiful photos, stamps, best-time-to-go, TEMPERATURE there ($0 via Open-Meteo, no key), how-far-to-reach (haversine → rough flight-time estimate, $0) — "anything that entices a vacation." Transit info (bus times): possible $0 via public GTFS feeds per agency — founder says NOT priority, parked. Audit workflow home-three-intents ran this session; implement its reorganization next.
